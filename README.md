# 🦝 浣熊 Raccoon — MoviePilot V3 插件

**你只管下和看：转种、删片腾空间、清死种，浣熊都替你收拾好。**

用 qBittorrent 下载、用 Transmission 做种的朋友，大概都烦过这几件事：

- 下完的种子要手动搬去 TR 做种，搬错、搬漏、搬过去才发现文件不全；
- 媒体库里删了片，磁盘空间却没回来——下载目录还留着一份在做种，删也不是留也不是；
- TR 里攒了一排红色死种记录，手动清怕误删，不清又碍眼；
- 在订的剧删了几集，半夜又被订阅默默补回来。

浣熊就是在后台默默干这些活的：下载、做种、删片、清死种全链路打通，你只管下和看。

## 功能

- **下载整理**：下完不用管，片子自动整理进媒体库，下载目录留原文件做种——看片、做种、文件规整一次到位。
- **QB转种TR**：告别手动搬种。qB 下完自动交棒 TR 做种，交接前逐个文件核对，缺文件当场拦下通知——不怕转过去才发现种是坏的。支持立即 / 每天一次 / 每周一三种时机，也可手动立即转种一次。
- **删片联动**：删了就真腾空间。媒体库里删掉，下载目录那份和种子记录跟着清；在订的剧删了自动停订阅，绝不偷偷补回来。
- **存量整理**：老库也不用重下。下载目录里的存量老片分批整理入库，硬链接成对登记，和新片一个待遇。
- **专辑整理（音乐）**：专辑自动归位。做种目录里的专辑按语种、歌手、专辑整理成库，重复的歌只留一份；原文件不动，做种不中断。
- **清死种记录**：告别一排红条。qB 和 TR 的死种每天先校验再清，完好的当场救活继续做种——不误杀，不用你手动挑。

## 安全设计

浣熊敢自动干活，是因为每个交接点都有据可查：

- **转种先核对**：按种子清单逐个核对磁盘文件，齐了才交接；不齐就拦下登记，补齐后自动放行。
- **删除三重闸**：删除执行前要过复活校验（等待期内文件被重新整理就自动取消）、硬链接数校验（文件还有别的硬链接绝不动）、inode 一致性校验（登记过期不删）。
- **死种先校验**：报错的种子先触发文件校验，完好排除并恢复做种，确认缺失才清记录；清记录前再按清单终核一遍，媒体文件还在绝不清。
- **审计流水**：每笔转种、删除、清记录都留一条带依据的流水，事后可对账。
- **可退回人工**：关掉「自动删除」后，所有删除先进待删清单，你逐项批准才执行；还有「试运行」模式，只报告不动手，适合先观察几天。

## 适用前提

- MoviePilot V3（`>=3.2.3, <4`）
- qBittorrent 与 Transmission 均已在 MoviePilot 中配置为下载器
- 下载目录与媒体库目录位于同一文件系统（媒体库整理使用硬链接）

## 安装

1. 在 MoviePilot 的插件市场中添加本仓库为插件源：`https://github.com/amufeng/MoviePilot-Plugins`
2. 在插件列表中找到「浣熊」，安装并启用
3. 打开插件配置，填好视频/音乐目录，按需打开功能开关
4. 第一次使用建议先开「试运行（只报告）」观察几天，确认无误再正式运行

## 注意

- 删片联动是**真删文件**腾空间（这正是它的目的），请先用试运行模式确认登记无误。
- 在订剧集被删会自动停掉那部订阅——这是有意设计，避免删完又被补下载。
- 音乐的「基础库」（你手工整理好的成品库）只会被当作整理基准读取，插件永不修改它。
